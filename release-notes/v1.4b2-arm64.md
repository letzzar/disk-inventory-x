First build of Disk Inventory X for **Apple Silicon**: the DMG is universal (arm64 + x86_64) and needs macOS 12 or later.

Based on Disk Inventory X 1.4b2 by Tjark Derlien (https://gitlab.com/tderlien/disk-inventory-x).

## Changes
  * Native arm64 build, current Xcode, macOS 12+.
  * No more OmniGroup frameworks: toolbar, preferences window and helpers rewritten natively.
    The preferences window gets a "Restore Defaults" button (English, Spanish, German, French).
  * 64-bit fixes in the file list data source (unsafe on arm64) and other integer truncations.
  * The treemap is drawn by the original [TreeMapView framework](https://github.com/letzzar/treemapview-framework),
    only patched to build for Apple Silicon. Its original repository does not state a license (Disk Inventory X
    is GPL v3); if a restrictive license is finally applied, it will be removed and rewritten from scratch.

## Installation
The app is ad-hoc signed (no Apple Developer ID). On first launch use right click → Open, or run
`xattr -dr com.apple.quarantine "/Applications/Disk Inventory X.app"`.

Tested on Apple Silicon (macOS 27). The Intel part is built but has not been run.
